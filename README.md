# My Book

Личная библиотека аудиокниг — устанавливаемое веб‑приложение (PWA) на чистом HTML/CSS/JS,
без сборки и зависимостей.

## Возможности

- Загрузка аудиофайлов (mp3, m4a, m4b, aac, ogg, opus, wav, flac). Несколько файлов,
  выбранных за раз, становятся главами одной книги (сортировка по имени файла).
- Название, автор и обложка читаются из тегов MP3 (ID3v2) и M4A/M4B; их можно изменить вручную.
- Плеер: play/пауза, стоп, −15/+30 с (через границы глав), ползунок, главы, скорость 0.5–3×,
  таймер сна, управление с экрана блокировки и наушников (Media Session API).
- Место прослушивания сохраняется постоянно и восстанавливается при следующем открытии.
- Работает офлайн (service worker).

Все файлы и прогресс хранятся **только на устройстве** (IndexedDB) — на сервер ничего не отправляется.

## Публикация

Это статические файлы — достаточно отдать корень репозитория как сайт:

- **Vercel:** New Project → выбрать репозиторий → Framework Preset «Other» → Deploy.
- **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)`.

Для работы service worker и установки на телефон нужен HTTPS (у обоих вариантов он есть).

## Установка на iPhone

Открыть адрес в Safari → «Поделиться» → «На экран „Домой“». Книги загружать уже из
установленного приложения (у Safari и у приложения разные хранилища).

## Локальный запуск

```sh
python3 -m http.server 8000
```

и открыть http://localhost:8000/
