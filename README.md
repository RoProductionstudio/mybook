# My Book

Личная библиотека аудиокниг: загружаете книгу на одном устройстве — она появляется на всех.
Книгу можно скачать на телефон и слушать без интернета. Место прослушивания синхронизируется
между устройствами.

Чистый HTML/CSS/JS без сборки + две функции Vercel в `api/`.

## Как устроено

- **Файлы** (аудио, обложки, метаданные, место прослушивания) хранятся в **Vercel Blob**.
  Браузер загружает аудио напрямую в Blob по подписанной ссылке (`api/upload.js` только выдаёт
  её через `handleUploadPresigned`), поэтому размер файла не ограничен лимитом функций.
- **`api/library.js`** — список книг (один запрос `list`), сохранение метаданных и места
  прослушивания, удаление книги.
- **Доступ** — по паролю из переменной окружения `MYBOOK_PASSWORD`. Пароль вводится один раз
  на каждом устройстве. Хранилище Blob **приватное**: аудио и обложки открываются только по
  подписанным временным ссылкам (на 7 дней), которые сервер выдаёт вместе со списком книг.
- **Офлайн** — кнопка «Скачать» сохраняет книгу в IndexedDB. На устройстве, с которого книга
  загружалась, она сразу доступна офлайн. Место прослушивания без сети сохраняется локально и
  отправляется на сервер, когда сеть появится.
- **Синхронизация** — место прослушивания отправляется на сервер при паузе, сворачивании
  приложения, смене главы/скорости и раз в 5 минут во время прослушивания. При открытии
  приложения берётся самая свежая позиция с любого устройства.

## Настройка в Vercel

1. **Storage → Create Database → Blob** → создать хранилище с доступом **Private** и
   подключить его к проекту `mybook` (Connect Project). Vercel сам добавит `BLOB_STORE_ID` и
   `BLOB_WEBHOOK_PUBLIC_KEY`, доступ к хранилищу идёт через OIDC — ключ `BLOB_READ_WRITE_TOKEN`
   не нужен.
2. **Settings → Environment Variables** → добавить `MYBOOK_PASSWORD` (ваш пароль).
3. **Deployments → … → Redeploy**, чтобы переменные подхватились.

## Лимиты бесплатного тарифа Vercel Blob (Hobby)

Ориентировочно: ~1 ГБ хранилища, ~10 ГБ скачиваний в месяц, ~2000 «сложных» операций в месяц
(загрузка файла, сохранение позиции, обновление списка). При превышении Vercel блокирует
хранилище до конца 30-дневного периода. Актуальные цифры — в разделе Usage проекта.
Приложение экономит операции: позиция отправляется не чаще раза в 15 секунд, список
обновляется не чаще раза в 2 минуты.

## Установка на iPhone

Safari → адрес приложения → «Поделиться» → «На экран „Домой“». Открывать с иконки.

## Обновление встроенной библиотеки загрузки

`vendor/blob-client.js` — функция `uploadPresigned` из `@vercel/blob@2.8.2/client`, собранная esbuild:

```sh
echo "export { uploadPresigned } from '@vercel/blob/client';" > entry.js
npx esbuild entry.js --bundle --format=esm --platform=browser --minify --target=es2020 \
  --outfile=vendor/blob-client.js --legal-comments=none \
  "--banner:js=var process=globalThis.process||{env:{}};"
```
